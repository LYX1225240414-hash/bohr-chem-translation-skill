# 化学文献术语一致性翻译 Skill

玻尔科学空间高校挑战赛 · 北京化工大学分站赛 —— 文献翻译赛题作品。

## 简介

面向化学 / 材料 / 催化方向英文科研论文的英译中 Skill。聚焦"术语表驱动的术语一致性翻译"，解决三个高频问题：同一术语前后译名不一致、长文漏段或错位、数字单位公式引用被译错。

核心设计：术语表是**执行依据**而非提示词装饰——每次翻译前强制重读术语表，每段译文必须有可回查的锚点，自检发现的问题写入 change_log 并回修。

## 目录结构

```

resources/glossary_template.json  术语表模板
resources/output_example.json     输出结构示意（非答案）
examples/README.md                最小调用示例
run/glossary.json                 真实试跑：术语表
run/result.json                   真实试跑：分段翻译结果 + 自检 + 修订记录
```

## 试跑说明

`run/` 下是对真实论文摘要（arXiv:2011.03269v1，TiO₂ 氧空位色心单重态）的完整试跑产物：6 段译文、10 条锁定术语、1 项不确定性标注、2 处自检回修。该试跑仅用于展示 Skill 工作流，不是赛题的正式测试案例或答案；正式评测由平台使用固定案例运行。

## 使用方式

在支持 Skill 的 Agent 环境中加载本目录，输入待翻译文献即可。Agent 按 SKILL.md 的 6 步流程执行：识别输入边界 → 抽取术语表 → 分段 → 逐段翻译 → 译后自检 → 输出结构化结果。
