# 译后自检清单

逐段核对，发现问题回到翻译步骤修正并记录。

## 术语一致性

- [ ] 术语表中每条术语在译文中的译名完全一致
- [ ] 标题、摘要、正文、图注、结论中的同一术语译名相同
- [ ] 缩写首次出现给出全称译名，后文统一
- [ ] 未出现"凭印象翻译但和术语表不一致"的条目

## 段落完整性

- [ ] `para_id` 数量与原文自然段数量一致
- [ ] 无漏段（尤其跨页、跨栏、章节衔接处）
- [ ] 无重复翻译、无段落错位
- [ ] 每段 `target` 与 `source` 一一对应

## 关系与事实

- [ ] 否定词（不、未、无、非、没有、fail、not、no）逐处保留
- [ ] 限定条件（仅、部分、显著、主要、may、can、significantly）未丢失或强化
- [ ] 指代对象（this、these、it、其、该）指向正确
- [ ] 因果、让步、对比关系未被改写
- [ ] 数字、单位、有效数字、上下标原样保留
- [ ] 公式、图表编号、文献引用标记原样保留

## 可核验性

- [ ] 每段译文有 `anchors`（页码/段落/图表/公式位置）
- [ ] 关键结论能回到原文具体位置
- [ ] 译不准、无法判断、材料冲突处写入 `uncertainties`
- [ ] `status` 与实际完成情况一致
